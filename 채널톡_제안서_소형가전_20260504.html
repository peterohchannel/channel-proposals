Problem · 스테나의 CS

소형가전 CS는
문의 유형이 가장 다양한 카테고리입니다.

설치·사용법부터 A/S 접수, 부품 교체까지 — 케이스마다 답변 기준이 달라
FAQ로 커버가 안 되고, 상담사가 건건이 대응해야 합니다.

🔧

설치·설정 방법 문의

"블루투스가 연결이 안 돼요" "어떤 콘센트에 꽂아야 하나요?" 구매 직후 설치 단계에서 발생하는 문의가 전체 CS의 35% 이상을 차지합니다.

🛠️

A/S 접수·수리 진행 상황

"A/S 맡긴 지 일주일 됐는데 언제 오나요?" A/S 접수부터 진행 상태 조회까지, 매번 고객이 직접 연락해야 하는 구조입니다.

🔄

반품·교환 처리

"박스 개봉했는데 불량이에요, 교환 가능한가요?" 가전 특성상 단순 변심·초기 불량 기준, 사진 증빙, 수거 방식 등 케이스가 복잡합니다.

🔩

소모품·부품 교체 문의

"필터 교체 주기가 언제에요?" "호환 부품을 어디서 살 수 있나요?" 모델마다 교체 기준이 달라 상담사가 직접 확인해야 합니다.

Call Reduction · 인입 콜 감소

반복 문의가 전화로 오기 전에,
AI가 먼저 끊어냅니다.

"고객이 채팅을 여는 순간, ALF가 즉시 해결합니다.
전화할 이유가 없어집니다."

슬룸은 월 최대 9,000건의 문의 중 91.4%를 ALF가 자동 해결 — 아웃소싱 월 3,500만원을 4인 인하우스로 대체했습니다.

1
즉시 응답

24시간 즉시 답변

고객이 문의하는 순간 ALF가 즉시 응답. 전화 연결 대기 없이 바로 해결합니다.

응답 대기 = 0 → 전화 전환율 급감
2
반복 문의 차단

설치·A/S·교환 자동 처리

설치 방법, A/S 접수, 교환·환불 기준 — 반복되는 문의 유형을 ALF가 전담합니다.

상담사에게는 진짜 복잡한 케이스만 전달
3
팀 규모 최적화

CS 팀 비용 구조 전환

콜·채팅 인입량이 줄면 인력 규모도 줄어듭니다. 슬룸은 아웃소싱을 완전히 없앴습니다.
